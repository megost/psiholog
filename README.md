# Сайт психолога Арины Шустовской — вариант 2 (иллюстрации)

Альтернативный дизайн: голубая палитра, кремовые и синие карточки, рисованные иллюстрации (inline SVG с «карандашной» текстурой).
Основная версия сайта — в ветке `main`.

- `index.html` — вся страница (HTML + CSS + SVG, без сборки)
- `assets/` — фото Арины и документы

Шрифт: Golos Text (Google Fonts).
